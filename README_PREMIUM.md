# MaksiShpi PREMIUM — инструкция по обновлению

В комплекте находятся готовые файлы для замены:

- `bot.py`
- `database.py`
- `game.py`
- `keyboards.py`
- `texts.py`
- `words.py`

Остальные файлы проекта менять не требуется.

## Что добавлено

- Подписка **MaksiShpi 𝗣𝗥𝗘𝗠𝗜𝗨𝗠** за **50 Telegram Stars каждые 30 дней**.
- Автоматическое продление подписки.
- Команда `/premium`.
- Команда `/terms`.
- Команда `/paysupport`.
- Отображение статуса и срока подписки.
- Блокировка премиум-категорий без активной подписки.
- Повторная проверка доступа непосредственно перед раздачей ролей.
- Подтверждение возраста 18+.
- Сохранение платежей и срока доступа в SQLite.
- Восстановление активных подписок из истории Telegram Stars после потери локальной базы.
- Сброс игры не удаляет купленный PREMIUM.

## Новые категории

### Бесплатные

- Все категории — 225 слов
- Знаменитости — 100 слов
- Локации — 75 слов
- Напитки — 50 слов

### PREMIUM

- Все слова PREMIUM — 305 записей
- Взрослые темы PREMIUM — 30 слов
- Профессии PREMIUM — 50 слов

Категория «Все слова PREMIUM» включает взрослые слова, поэтому перед её выбором тоже показывается подтверждение 18+.

## Перед обновлением

1. Не удаляйте репозиторий.
2. Не удаляйте `.env` и переменные окружения на хостинге.
3. Не публикуйте токен бота на GitHub.
4. Желательно сохранить копию старых файлов.

## Замена файлов на GitHub

Для каждого из шести файлов:

1. Откройте репозиторий `rubychka001/MaksiShpi`.
2. Откройте нужный старый файл.
3. Нажмите значок карандаша.
4. Удалите старое содержимое.
5. Вставьте содержимое нового файла.
6. Нажмите `Commit changes`.

Более простой способ:

1. Нажмите `Add file`.
2. Выберите `Upload files`.
3. Перетащите все шесть файлов из этого комплекта.
4. GitHub предложит заменить файлы с совпадающими именами.
5. Нажмите `Commit changes`.

В корне репозитория названия должны остаться строго такими:

```text
bot.py
database.py
game.py
keyboards.py
texts.py
words.py
```

Не помещайте их во вложенную папку.

## Переменные окружения

Новые переменные не нужны. Оставьте существующие:

```text
BOT_TOKEN=ваш_токен
DATABASE_PATH=data/maksishpi.db
LOG_LEVEL=INFO
```

`BOT_TOKEN` на GitHub добавлять нельзя.

Для Telegram Stars не требуется токен стороннего платёжного провайдера.

## Обновление на Bothost

1. Откройте карточку бота.
2. Убедитесь, что ветка указана `main`.
3. Нажмите пересборку или повторное развёртывание.
4. Откройте «Логи сборки».
5. Дождитесь успешного завершения.
6. Откройте «Логи работы».
7. Найдите строку:

```text
Бот @имя_бота запущен
```

Если появляется ошибка, скопируйте последние 30 строк лога.

## Первый запуск после обновления

При запуске бот автоматически создаст таблицы:

- `premium_subscriptions`
- `premium_payments`
- `app_settings`

Существующая таблица игровых сессий останется на месте.

Бот также проверит недавнюю историю Telegram Stars. Это позволяет восстановить действующие подписки, если локальная SQLite-база была удалена при пересборке хостинга.

## Проверка без оплаты

1. Отправьте `/start`.
2. Проверьте кнопку `💎 Открыть PREMIUM`.
3. Начните настройку игры.
4. Откройте выбор категорий.
5. У премиум-категорий должны отображаться замки.
6. Нажмите на закрытую категорию.
7. Должна появиться кнопка оплаты `⭐ Оплатить 50 ⭐`.
8. Откройте оплату и закройте окно, не подтверждая её.

До подтверждения Telegram Stars не должны списываться.

## Проверка реальной оплаты

В производственном Telegram оплата списывает настоящие Telegram Stars.

1. Нажмите `⭐ Оплатить 50 ⭐`.
2. Подтвердите оплату.
3. Бот должен показать сообщение об успешной подписке.
4. Отправьте `/premium`.
5. Проверьте дату окончания подписки.
6. Вернитесь к категориям.
7. Замки должны исчезнуть.
8. Откройте «Профессии PREMIUM».
9. Откройте «Взрослые темы PREMIUM».
10. Перед взрослой категорией подтвердите возраст.

## Как работает продление

- Первый платёж открывает доступ на 30 дней.
- Telegram автоматически пытается списать ещё 50 Stars через 30 дней.
- После успешного продления бот получает новый платёж и обновляет срок доступа.
- Если пользователь отменил автопродление, доступ сохраняется до конца оплаченного периода.
- Если продление не прошло, бот отправит предупреждение.

## Где менять цену

Цена хранится в `texts.py`:

```python
PREMIUM_PRICE_STARS = 50
```

`bot.py` берёт значение из `texts.py`, поэтому достаточно изменить цену в одном месте.

После изменения цены необходимо удалить старую сохранённую ссылку счёта из таблицы `app_settings` либо изменить в `bot.py` значение:

```python
PREMIUM_INVOICE_SETTING = "premium_invoice_link_v2"
```

Иначе может использоваться старая ссылка с прежней ценой.

## Где менять ссылку поддержки

В `texts.py`:

```python
SUPPORT_URL = "https://t.me/MaksiGamesBots"
```

Лучше использовать отдельный аккаунт или группу поддержки, в которую пользователь действительно может написать.

## Важные ограничения

- PREMIUM привязан к Telegram ID покупателя.
- В одной игре остальные участники покупать подписку не должны, поскольку телефон и бот принадлежат организатору.
- Сброс игровых настроек не удаляет PREMIUM.
- Бесплатная категория «Все категории» не содержит премиум-слов.
- «Все слова PREMIUM» содержит бесплатные категории, взрослые темы и профессии.
- Если подписка закончилась после выбора категории, бот повторно проверит доступ перед раздачей и не позволит запустить премиум-раунд.
- При потере базы игровые имена и настройки могут исчезнуть, но действующая PREMIUM-подписка восстанавливается из истории Stars.
