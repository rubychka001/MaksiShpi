# MaksiShpi — Telegram-бот для игры «Кто шпион?»

Готовый бот для игры с одним телефоном. Игроки по очереди смотрят роль, после нажатия «Я увидел» сообщение с ролью удаляется. Настройки и состав сохраняются в SQLite и остаются после перезапуска.

## Что уже реализовано

- приветствие, правила и красивое меню;
- от 3 до 20 игроков;
- от 1 до 5 шпионов, при этом остаётся минимум два мирных;
- ввод уникальных имён;
- категории: все слова, знаменитости, места, напитки;
- 200 слов: 100 знаменитостей, 50 мест и 50 напитков;
- секретная поочерёдная раздача ролей;
- удаление открытой роли перед передачей телефона;
- начало и завершение раунда;
- раскрытие слова и шпионов;
- следующий раунд с сохранением состава и настроек;
- добавление, удаление и переименование игроков;
- изменение категории и количества шпионов;
- защита от повторных нажатий и устаревших кнопок;
- хранение данных в SQLite;
- необязательные стикеры в приветствии и итогах;
- запуск на Windows, Linux/VDS и Docker;
- журнал ошибок в `logs/bot.log`.

# Запуск на Windows — от А до Я

## 1. Создайте бота в Telegram

1. Откройте официальный бот `@BotFather`.
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя: `MaksiShpi`.
4. Введите свободный username, который обязательно заканчивается на `bot`, например `MaksiShpiBot`.
5. BotFather пришлёт токен вида `123456789:AA...`.
6. Никому не отправляйте этот токен и не публикуйте файл `.env`.

## 2. Установите Python

Рекомендуется Python 3.12. При установке обязательно отметьте галочку **Add Python to PATH**.

Проверка в командной строке:

```bat
py --version
```

## 3. Подготовьте проект

1. Распакуйте архив `MaksiShpi.zip`.
2. Откройте папку `MaksiShpi`.
3. Скопируйте файл `.env.example`.
4. Переименуйте копию в `.env`.
5. Откройте `.env` обычным Блокнотом.
6. Замените строку:

```env
BOT_TOKEN=ВСТАВЬТЕ_ТОКЕН_СЮДА
```

на свой токен, например:

```env
BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Не добавляйте кавычки и пробелы.

## 4. Запустите

Дважды нажмите файл:

```text
start_windows.bat
```

При первом запуске автоматически создастся виртуальное окружение и установятся библиотеки. Когда в консоли появится строка `Бот @... запущен`, откройте своего бота и отправьте `/start`.

Чтобы бот работал, окно консоли должно оставаться открытым. Для круглосуточной работы используйте VDS или Docker.

## Ручной запуск через командную строку

```bat
cd ПУТЬ\К\MaksiShpi
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python bot.py
```

Остановка: `Ctrl + C`.

# Проверка всех функций

Пройдите этот сценарий:

1. `/start` → «Начать игру».
2. Выберите 4 игроков.
3. Выберите 1 шпиона.
4. Выберите «Места».
5. Введите четыре разных имени.
6. На экране настроек измените одно имя.
7. Добавьте игрока, затем удалите его.
8. Нажмите «Раздать роли».
9. Для каждого игрока нажмите «Показать мою роль», запомните её и нажмите «Я увидел».
10. Убедитесь, что показанная роль удаляется из истории.
11. Запустите раунд и завершите его.
12. Проверьте, что итог показывает правильное слово и нужное количество шпионов.
13. Нажмите «Следующий раунд» — должен открыться экран сохранённых настроек.
14. Перезапустите бот — состав должен сохраниться.

Автоматическая проверка логики:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

# Добавление своих стикеров

1. Запустите бот.
2. Отправьте команду `/stickerid`.
3. Следующим сообщением отправьте нужный стикер.
4. Бот пришлёт `file_id`.
5. Вставьте его в `.env`:

```env
WELCOME_STICKER_ID=сюда_file_id_приветственного_стикера
RESULT_STICKER_ID=сюда_file_id_итогового_стикера
```

6. Перезапустите бот.

Пустые значения разрешены — бот будет работать без стикеров.

# Изменение слов

Все списки находятся в `words.py`:

- `CELEBRITIES` — знаменитости;
- `PLACES` — места;
- `DRINKS` — напитки.

Добавляйте новые слова в кавычках через запятую:

```python
PLACES = [
    "Больница",
    "Тюрьма",
    "Новый вариант",
]
```

После изменения перезапустите бот.

# Круглосуточный запуск на Ubuntu/VDS

## 1. Установка

```bash
sudo apt update
sudo apt install -y python3 python3-venv unzip
```

Загрузите папку проекта на сервер, затем:

```bash
cd /путь/к/MaksiShpi
cp .env.example .env
nano .env
```

Вставьте токен, сохраните: `Ctrl+O`, Enter, затем `Ctrl+X`.

Первый запуск:

```bash
chmod +x start_linux.sh
./start_linux.sh
```

## 2. Автозапуск через systemd

Узнайте абсолютный путь:

```bash
pwd
```

Создайте службу:

```bash
sudo nano /etc/systemd/system/maksishpi.service
```

Пример, замените `/home/user/MaksiShpi` на свой путь и `user` на пользователя сервера:

```ini
[Unit]
Description=MaksiShpi Telegram Bot
After=network.target

[Service]
Type=simple
User=user
WorkingDirectory=/home/user/MaksiShpi
ExecStart=/home/user/MaksiShpi/.venv/bin/python /home/user/MaksiShpi/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Запустите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now maksishpi
sudo systemctl status maksishpi
```

Логи службы:

```bash
journalctl -u maksishpi -f
```

Перезапуск после изменения кода:

```bash
sudo systemctl restart maksishpi
```

# Запуск через Docker

Установите Docker, создайте `.env`, затем выполните:

```bash
docker compose up -d --build
```

Просмотр логов:

```bash
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

База и логи остаются в локальных папках `data` и `logs`.

# Частые ошибки

## `Не найден BOT_TOKEN`

Нет файла `.env`, он назван `.env.txt` или токен не вставлен. В проводнике Windows включите отображение расширений файлов.

## `Unauthorized` или `Token is invalid`

Токен введён неправильно либо был отозван в BotFather. Получите новый токен и замените его в `.env`.

## Бот не отвечает

- проверьте, что консоль не закрыта;
- посмотрите `logs/bot.log`;
- убедитесь, что запущена только одна копия бота;
- перезапустите программу;
- убедитесь, что интернет не блокирует Telegram API.

## `Conflict: terminated by other getUpdates request`

Одновременно работают две копии бота. Закройте лишнюю копию или остановите старую службу/VDS.

## После изменения `.env` ничего не поменялось

Полностью перезапустите процесс бота.

## Важное ограничение Telegram

Режим рассчитан на личный чат с ботом и передачу одного телефона. Не добавляйте бота в общий групповой чат для раздачи ролей: участники смогут увидеть чужие сообщения.
