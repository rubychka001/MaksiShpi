# MaksiShpi — PREMIUM, админ-панель и обновлённое оформление

Этот комплект заменяет текущую PREMIUM-версию бота и добавляет:

- отдельную админ-панель;
- кнопку админ-панели только для ID из `ADMIN_IDS`;
- дополнительную проверку прав на каждой админской кнопке;
- рассылку сообщений всем пользователям;
- выдачу PREMIUM на 30, 90, 180, 365 дней или без ограничения срока;
- ручное отключение PREMIUM;
- поиск пользователя по Telegram ID;
- статистику пользователей, подписок, платежей, раундов и рассылок;
- автоматическое сохранение пользователей в SQLite;
- перенос старых пользователей из таблицы игровых сессий;
- более аккуратные, понятные и человечные тексты интерфейса.

## 1. Какие файлы заменить

В корне GitHub-репозитория замените эти файлы:

```text
bot.py
database.py
keyboards.py
texts.py
config.py
game.py
words.py
```

Лучше загрузить все семь файлов из комплекта одновременно. Так версии точно будут совместимы между собой.

Не меняйте:

```text
Dockerfile
requirements.txt
.gitignore
```

Новые библиотеки не нужны. Текущие зависимости `aiogram`, `aiosqlite` и `python-dotenv` подходят.

## 2. Как заменить файлы на GitHub

1. Откройте репозиторий `MaksiShpi`.
2. Нажмите **Add file → Upload files**.
3. Выделите семь файлов из папки комплекта.
4. Перетащите их в окно GitHub.
5. GitHub покажет, что файлы с такими именами будут обновлены.
6. Внизу нажмите **Commit changes**.
7. Убедитесь, что файлы находятся в корне репозитория рядом с `Dockerfile` и `requirements.txt`.

## 3. Переменные окружения Bothost

В панели Bothost должны остаться:

```text
BOT_TOKEN=токен_бота
DATABASE_PATH=data/maksishpi.db
LOG_LEVEL=INFO
ADMIN_IDS=1314228090
```

Где `1314228090` — Telegram ID администратора.

Для нескольких администраторов:

```text
ADMIN_IDS=1314228090,987654321
```

Пробелы лучше не использовать.

После изменения переменных обязательно полностью перезапустите или пересоберите контейнер. Уже запущенный процесс не подхватит новое значение `ADMIN_IDS`.

## 4. Пересборка на Bothost

После загрузки файлов:

1. Откройте проект бота в Bothost.
2. Нажмите **Пересобрать**, **Повторно развернуть** или аналогичную кнопку.
3. Дождитесь завершения сборки.
4. Откройте логи работы.
5. Проверьте, что внизу появилась строка:

```text
Бот @имя_бота запущен
```

В логах не должно быть сообщения:

```text
ADMIN_IDS не задан
```

Через Web Terminal можно выполнить:

```text
env
```

В выводе должна присутствовать строка:

```text
ADMIN_IDS=1314228090
```

## 5. Как открыть админ-панель

После перезапуска отправьте боту:

```text
/start
```

У администратора появится кнопка:

```text
🛠 Админ-панель
```

У обычных пользователей этой кнопки нет.

Запасной способ открытия:

```text
/admin
```

Даже если обычный пользователь вручную подделает callback-кнопку, код повторно проверит его Telegram ID и не даст доступ.

## 6. Разделы админ-панели

### Статистика

Показывает:

- общее число пользователей;
- число доступных для рассылки;
- активность за 24 часа и 7 дней;
- действующие PREMIUM-доступы;
- платные и ручные PREMIUM-доступы;
- количество успешных платежей;
- сумму полученных Telegram Stars;
- количество сыгранных раундов;
- количество проведённых рассылок.

### Рассылка

1. Нажмите **📢 Рассылка**.
2. Отправьте сообщение в том виде, в котором его должны увидеть пользователи.
3. Можно отправить текст, фото, видео, документ, аудио, голосовое сообщение, GIF или стикер.
4. Бот покажет предпросмотр и количество получателей.
5. Нажмите **🚀 Начать рассылку**.
6. Дождитесь итогового отчёта.

Бот отправляет копию исходного сообщения, поэтому сохраняются:

- форматирование текста;
- подпись к фотографии или видео;
- медиафайл;

Пользователи, которые заблокировали бота, отмечаются как недоступные и больше не участвуют в следующих рассылках, пока снова не напишут боту.

Важно: бот может писать только тем пользователям, которые раньше самостоятельно открывали его.

### Выдать PREMIUM

1. Нажмите **💎 Выдать PREMIUM**.
2. Отправьте Telegram ID пользователя.
3. Выберите срок:
   - 30 дней;
   - 90 дней;
   - 180 дней;
   - 365 дней;
   - без ограничения срока.
4. Доступ включится сразу.
5. Пользователь получит уведомление от бота.

Если PREMIUM уже активен, выбранный срок прибавится к текущей дате окончания.

Ручная выдача не списывает Telegram Stars и не включает автоматическое продление.

### Забрать PREMIUM

1. Нажмите **🛑 Забрать PREMIUM**.
2. Отправьте Telegram ID.
3. Проверьте текущий срок.
4. Подтвердите отключение.

Важно: ручное отключение закрывает доступ в локальной базе, но не отменяет автопродление настоящей платной подписки Telegram. Платное автопродление пользователь отменяет в своём Telegram.

### Найти пользователя

Показывает:

- Telegram ID;
- имя;
- username;
- язык Telegram;
- доступность для сообщений;
- первый запуск;
- последнюю активность;
- состояние PREMIUM.

Из карточки пользователя можно сразу выдать или забрать PREMIUM.

## 7. Команды администратора

Команды оставлены как запасной способ:

```text
/admin
/grantpremium
/revokepremium
/stickerid
```

Примеры:

```text
/grantpremium 123456789 30
/revokepremium 123456789
```

Выдать 30 дней самому себе:

```text
/grantpremium
```

Узнать свой ID:

```text
/myid
```

## 8. Что происходит с базой данных

База остаётся по текущему пути:

```text
data/maksishpi.db
```

При первом запуске обновлённый код автоматически создаст новые таблицы:

```text
users
broadcasts
premium_subscriptions
premium_payments
premium_manual_grants
app_settings
```

Существующие игровые сессии и PREMIUM-подписки не удаляются.

Старые `chat_id` из таблицы игровых сессий автоматически добавляются в таблицу пользователей. Имя и username обновятся, когда человек снова откроет бота или нажмёт кнопку.

Команда сброса игры удаляет только игровые настройки. PREMIUM и данные для админ-панели сохраняются.

## 9. Безопасность

Не загружайте в GitHub:

```text
.env
data/maksishpi.db
logs/bot.log
```

Файл `.gitignore` должен исключать `.env`, `data/`, `*.db` и `logs/`.

Админ-панель защищена двумя уровнями:

1. кнопка показывается только администраторам;
2. каждый обработчик повторно проверяет ID через `CONFIG.admin_ids`.

## 10. Проверка после установки

Проверьте по порядку:

1. `/myid` показывает ID из `ADMIN_IDS`.
2. `/start` показывает кнопку **🛠 Админ-панель**.
3. Обычный аккаунт этой кнопки не видит.
4. Раздел статистики открывается.
5. Поиск находит администратора после `/start`.
6. Выдача PREMIUM на 30 дней работает.
7. `/premium` показывает активный срок.
8. Тестовая рассылка приходит на второй аккаунт.
9. Бесплатная игра и раздача ролей продолжают работать.
10. Оплата PREMIUM через Telegram Stars открывает платные категории.

## 11. Если кнопка админ-панели не появилась

1. Отправьте `/myid` и сравните номер с `ADMIN_IDS`.
2. В Bothost откройте Web Terminal и выполните `env`.
3. Проверьте точное имя переменной: `ADMIN_IDS`.
4. Полностью пересоберите или перезапустите контейнер.
5. Проверьте, что новый `config.py` действительно загружен в GitHub.
6. Отправьте боту `/start` заново.

Если `env` показывает правильный ID, но доступ всё равно запрещён, значит контейнер работает со старым коммитом. Запустите полную пересборку из ветки `main`.
